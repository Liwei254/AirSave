# 🧠 FEATURE PLANNING SYSTEM

Every feature MUST follow this structure:

---

# 🎯 FEATURE NAME

## Goal
What are we building?

## User Flow
Step-by-step user journey

## Backend Changes
- Controllers
- Routes
- Models

## Frontend Changes
- Pages
- Components
- API calls

## Risks
- What can break?

## Done Criteria
- What defines success?

---

# ✅ EXAMPLE

## Feature: Goal Selection

Goal:
User selects which goal to save to

User Flow:
- Enter amount
- Select goal
- Save

Backend:
- Accept goalId
- Update selected goal

Frontend:
- Add dropdown
- Pass goalId

Done:
- Only selected goal updates
