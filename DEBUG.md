# 🧠 DEBUG SYSTEM

When an error occurs:

---

# 🔍 STEP 1: IDENTIFY

- What is the error?
- Where is it happening?

---

# 🔎 STEP 2: TRACE

Frontend → API → Backend → DB

---

# 🧠 STEP 3: ROOT CAUSE

Common causes:

- Missing token → 401
- Wrong data type → 400
- Wrong route → 404
- Server crash → 500

---

# 🔧 STEP 4: FIX

- Fix source, not symptom
- Keep solution simple

---

# ✅ STEP 5: VERIFY

- Test again
- Check console
- Confirm UI updates

---

# 🚫 NEVER

- Guess fixes
- Patch blindly
- Ignore logs
